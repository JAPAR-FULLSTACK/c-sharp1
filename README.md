

# 🚀 C# Programming Practice & Projects

Welcome to the **C# Programming Practice** repository! This repository contains a collection of exercises, practices, and hands-on projects developed as part of learning C# and .NET fundamentals.

---

## 📌 About The Project

This repository serves as a personal laboratory for learning C# syntax, object-oriented programming (OOP) principles, logic building, and practical applications.

### Key Highlights:
- **Core Concepts:** Variables, Data Types, Conditionals, Loops, and Functions.
- **Object-Oriented Programming (OOP):** Classes, Objects, Inheritance, Polymorphism, Abstraction, and Encapsulation.
- **Practical Exercises:** Hands-on console applications and task assignments.
